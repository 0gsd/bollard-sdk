# Contributing

Thank you for looking. For now this repository does not take pull requests: the platform's
specifications are still drafts and the SDK is moving quickly, so a pull request opened here is
closed automatically with a note.

What helps most right now:

- **Issues.** Bugs, unclear documentation, things the SDK does not let you do.
- **Ideas for partnerships, docks and dev kits.** Write to shake@bollawax.org, or use the
  contact form on https://popboll.com.

This will change once the specifications settle.
