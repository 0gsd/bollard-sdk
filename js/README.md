# js: the browser and Node binding

Plain JavaScript. No build step, no bundler, no packages. It runs from a `<script>` tag, from
`require()` and as an ES module, and the same files run under Node in the tests.

```html
<script src="js/bollardeck.js"></script>
<script>
  bollardeck.schema.validate("cue", [{button: 4, state: "on", role: null}]);   // [#/0/button: must be one of 1, 2, 3, not 4]
  bollardeck.cues.at([{button: 1, state: "pulse", role: "go"}], performance.now());
  bollardeck.matrix.toHex(bollardeck.matrix.glyph("boot", 0));
</script>
```

```js
const bollardeck = require("./js/bollardeck.js");                    // Node, CommonJS
import bollardeck, { schema, cues, matrix, constants } from "./js/bollardeck.mjs";   // ES module
```

`examples/browser/index.html` is a page that does this from disk, with no server.

## The files

| File | Defines | Needs a page? |
| :--- | :--- | :--- |
| `bollardeck.js` | `bollardeck`: `version`, `speaks`, `minBollawax`, `constants`, `ready`, `parts`. It loads the files below. | no |
| `bollardeck.schemas.js` | `bollardeck.schemas`: the JSON Schemas by name. Generated by `tools/generate.py`. | no |
| `bollardeck.schema.js` | `bollardeck.schema`: the validator. | no |
| `bollardeck.cues.js` | `bollardeck.cues`: what each button shows at a time. | no |
| `bollardeck.matrix.js` | `bollardeck.matrix`: the LED matrix frame engine. | no |
| `bollardeck.gestures.js` | `bollardeck.gestures`: button presses in, gestures out. | no |
| `bollardeck.keymap.js` | `bollardeck.keymap`: what a gesture means. | no |
| `bollardeck.corpus.js` | `bollardeck.corpus`: the corpus gate, and a hub client on `fetch`. | no (the hub client needs `fetch`) |
| `bollardeck.dom.js` | `cues.apply`, `cues.run`, `matrix.canvas`, `gestures.listen`: the optional page helpers. | only when called |
| `bollardeck.constants.js` | `bollardeckConstants`: the constants alone. Generated by `tools/generate.py`. | no |
| `bollardeck.mjs` | The ES module entry: a default export and named exports. | no |

Keep the files together in one folder: `bollardeck.js` finds its parts beside itself.

## Loading

- **One plain tag** in the page's HTML. `bollardeck.js` writes a tag for each part, so they run in
  order before the next `<script>` in the page. A `?v=…` on the tag's URL is passed on to the parts.
- **A tag that is `async`, `defer` or added by script.** The parts are added after it and run in
  order. Wait for `bollardeck.ready`, a promise of the `bollardeck` object. It rejects, naming the
  file, when a part did not load.
- **Some of the parts.** `data-parts="cues matrix"` on the tag (names separated by spaces or
  commas) loads those parts and no others, in the same two ways, and `bollardeck.ready` waits for
  them only. A name that is not a part loads nothing and rejects `bollardeck.ready`.
- **Your own tags.** Put `data-parts="none"` on the `bollardeck.js` tag and add a tag for each part
  you want, in any order, before or after it. A part works without the others where it can:
  `bollardeck.matrix.js` alone is a complete matrix engine.
- **`require("./js/bollardeck.js")`** loads everything. Requiring a part returns that part's
  namespace (`require("./js/bollardeck.matrix.js")` is `bollardeck.matrix`).
- **`import … from "./js/bollardeck.mjs"`** loads everything and has `version`, `speaks`,
  `minBollawax`, `constants`, `schemas`, `schema`, `cues`, `matrix`, `gestures`, `keymap` and
  `corpus` as named exports.
- **A worker.** `importScripts()` each file; `bollardeck.js` loads no parts where there is no
  document.

## bollardeck.schema

The twin of `python/bollardeck/schema.py`: the same keywords, the same refusals, the same verdict
on every vector in `conformance/index.json`.

| | |
| :--- | :--- |
| `validate(name, value)` | Every problem with `value` as a document of the schema `name`; `[]` when it is fine. `name` may point inside a schema: `"cue#/$defs/cue"`. |
| `isValid(name, value)` | `true` when `validate` finds nothing. |
| `names()` | The schema names. |
| `load(name)` | The schema, frozen. A name it does not know is a `RangeError`. |
| `check(schema, where)` | Throws `UnsupportedSchema` unless every keyword is one this validator implements. |
| `use({name: schema})` | Validate against these schemas from now on (for a page that fetched newer ones). All are checked first. |
| `KEYWORDS`, `ANNOTATIONS`, `TYPES`, `DIALECT` | What it implements. |
| `Problem` | `{pointer, message, keyword}`; `pointer` is an RFC 6901 JSON pointer, `""` for the document itself. `String(problem)` is `"#/scope: must be …"`. |
| `UnsupportedSchema` | The error for a schema it cannot enforce. |

## bollardeck.cues

Buttons are numbered 1, 2, 3. A cue list is a document of the `cue` schema, with at most one cue
per button.

| | |
| :--- | :--- |
| `at(list, tMs, {calm})` | Three entries, for buttons 1, 2, 3. The list is checked the first time it is seen; pass a new list to change the cues. |
| `compile(list)` | Check once and get `{cues, at(tMs, {calm})}`. Throws a `TypeError` with `.problems` for a list that is not valid. |
| `problems(list)` | The `cue` schema's problems, plus a second cue for one button. |
| `pulseLevel(tMs)`, `chaseHead(tMs)` | The two animations by themselves. |
| `normalise(list)` | The cue list every renderer wants, from anything: never throws, drops a cue it cannot use, keeps the last of two cues for one button. Always valid. |
| `repairs(list)` | What `normalise` dropped or changed: `[{index, kind, message, dropped}]`. |
| `BUTTONS`, `PULSE_FLOOR`, `CHASE_TAIL`, `CHASE_STEPS` | `[1, 2, 3]`, and three values read from `bollardeck.constants` (`0.35`, `0.25`, `3`). |

An entry is `{button, driven, state, role, level, arc, head, pixel}`: `driven` is false when the
list has no cue for the button; `level` is 0..1 for a single lamp; `arc` is three levels for a
surface that draws a button as three lamps; `head` is the lamp leading a chase; `pixel` is `level`
as 0..255. `{calm: true}` (reduced motion) draws `pulse` and `chase` as `on`. Periods come from
`bollardeck.constants` (`PULSE_PERIOD_MS`, `CHASE_PERIOD_MS`); pass `{pulsePeriodMs, chasePeriodMs}`
to override them.

From `bollardeck.dom.js`:

| | |
| :--- | :--- |
| `apply(elements, entries, {properties, undriven})` | Sets `data-cue`, `data-cue-role`, `--cue-level` and `--cue-head` on `{1: el, 2: el, 3: el}` or `[el1, el2, el3]`, and removes them from a button that is not driven. Your stylesheet draws it. `properties: false` writes no custom property, so no element gains a `style` attribute; `undriven: "off"` writes `data-cue="off"` on a button that is not driven instead of removing the attribute. |
| `run(elements, cues, {calm, now, properties, undriven})` | `apply` every animation frame; `cues` is a list or a function returning one. Returns `{stop()}`. `calm` defaults to the reader's reduced-motion setting. |

## bollardeck.matrix

The frame engine of the device's 13 × 8 LED matrix and three RGB LEDs. A frame is
`{pixels: [104 × 0..255], rgb: [[r, g, b], [r, g, b], [r, g, b]]}`, row-major, row 0 at the top;
the LEDs are LED1, LED3 and LED4. Every frame is a pure function of its arguments.

| | |
| :--- | :--- |
| `film(song, tMs, calm)` | The making-of film at film time `tMs`. |
| `playback(song, posS, calm)` | Playback at `posS` seconds. |
| `idle(tMs, calm, temperament)` | The breathing heart. |
| `corpus(tMs, level, bands, calm)` | A spinning record and a level meter. |
| `glyph(name, tMs, calm)` | One of `GLYPHS`. |
| `dj(seg, posS, tMs, calm)` | A mix segment: platters, crossfader, key, judges, riser, drop. |
| `text(text, tMs, loop, priority, ttlMs, calm)` | 5 × 7 text; `textPassMs(text)` is how long one pass takes. |
| `premiere(number, tMs, opened, calm, tier)` | A series box waiting, or bursting open. |
| `tone(frame, tone)` | A brightness curve and RGB tint on any frame. |
| `toHex(frame)`, `fromHex(hex)`, `toBytes(frame)`, `ascii(frame)` | The 113-byte wire form as hex or bytes, and eight lines of text for a console. |
| `djBeat`, `djCrossfader`, `djCamelot`, `filmReel`, `songSeed`, `strSeed` | The engine's helpers. |
| `W`, `H`, `N`, `FRAME_BYTES`, `TICK_MS`, `GLYPHS`, `COLS`, `PALETTE`, `PREMIERE_PERIOD_MS`, `PREMIERE_OPEN_MS` | 13, 8, 104, 113, 90, and the engine's tables. |

`calm` is reduced motion. Numbers may arrive as decimal strings; text must be a string; anything
malformed is read as absent, never thrown.

From `bollardeck.dom.js`: `canvas(canvasElement, {lamp, background, leds, fps})` returns
`{draw(frame), run(frameFn), stop()}`. `run` calls `frameFn(nowMs)` every animation frame and
draws the frame it returns.

## bollardeck.gestures

The twin of `python/bollardeck/device/gestures.py`, held to `conformance/gestures/timelines.json`.
A pure state machine: it never reads a clock, every call carries a time in milliseconds, and time
must not run backwards (the engine throws; a host that mixes two clocks clamps before it calls).
The ten rules are at the top of `bollardeck.gestures.js`.

| | |
| :--- | :--- |
| `engine({holdMs, tapFollowMs, combos, pressLostMs})` | A new engine. The defaults are `HOLD_MS`, `TAP_FOLLOW_MS`, `PRESS_LOST_MS` and the combos the platform keymap names (`{1: [3], 3: [3]}`). |
| `engine.setCombos(combos)` | Change the combos of a running engine (`null`: the keymap's). A button that is down stays down and pending taps stay pending; taps that can no longer become a combo are reported by the next call. |
| `engine.down(b, tMs)`, `.up(b, tMs)`, `.cancel(b, tMs)`, `.tick(tMs)` | Feed it. Each returns the gestures that became certain, oldest first. |
| `engine.nextDeadlineMs()` | When the next `tick` will have something to say, or `null`. One timer set to this replaces a hold timer and a chain timer. |
| `engine.press(b, downMs, upMs)`, `.key(event, nowMs)`, `.feed(event)`, `.run(events)` | A whole press; a device key event; a vector's event; a list of them. |
| `engine.pending()`, `.isDown(b)`, `.waiting(b)`, `.holdMs`, `.tapFollowMs`, `.pressLostMs`, `.combos` | Its state and settings. `waiting` is true while a key source has announced a press whose release has not been read. |
| `gestureName(kind, button, count)`, `parseGesture(name)`, `combosFromKeymap(keymap)` | Names, and the combos a keymap needs. |

A gesture is `{name, button, kind, count, tMs, holdMs}`: `name` is `tap1`, `tap3x3` or `hold2`,
`tMs` is when it became certain, and `holdMs` is how long its press lasted (a chain's last tap;
the engine's `holdMs` for a hold that fires while the button is still down). A button that is not 1, 2 or 3, and a time that runs backwards, throw a
`RangeError`.

`key(event, nowMs)` takes the device's key events. A complete press `{i: button, down: 0, hold_ms,
t_ms}` is a tap or a hold by its `hold_ms` alone, never by when it is read. `{i: button, down: 1,
t_ms}` is a press beginning: a hint, never a gesture. It keeps a `tick` that runs while the next
press of a chain is held from reporting the taps so far as singles, and a beginning whose release
never comes is a lost press that yields nothing. A release that states its own `t_ms` belongs to
an announced press only when the press it describes began within `PRESS_MATCH_MS` of the
announcement; otherwise it stands alone, at its own times. (Until 0.1.0 a press beginning was fed as an
edge, so a release read late became a hold.)

From `bollardeck.dom.js`: `listen(elements, onGesture, opts)` feeds an engine from pointer events
on three elements, from Space or Enter on a focused one and from the keys 1, 2, 3, keeps the one
timer, and returns `{engine, edge(kind, button), setCombos(combos), stop()}`. A cancelled pointer, and an element or
the window losing focus, cancel the press. `opts`: `engine`, or `holdMs`,
`tapFollowMs`, `combos`; `keys` (key to button) and `keyTarget` (`null` for no keys); `now`;
`raw(button)` and `onEdge(button, "down" | "up", tMs)` for a prompt that takes press and release
times itself; `onChange(button, isDown, {tMs, raw, kind})` for every press beginning and ending,
raw or not, called before the gesture that edge completes (for drawing a pressed button).
`setCombos(combos)` changes the combos while it listens and drops nothing in flight. `stop()`
cancels a press in flight and tells `onChange` (kind `"cancel"`).

## bollardeck.keymap

The twin of `python/bollardeck/device/keymap.py`, held to `conformance/gestures/resolve.json`.
Keymap version 2. The platform's keymap is `bollardeck.constants.KEYMAP`.

| | |
| :--- | :--- |
| `resolve(gesture, prompt, keymap)` | What the gesture means while a prompt of kind `prompt` is showing (`null`: none). `keymap` defaults to the platform's. |
| `isGesture(name)` | Is this a gesture name? Never throws, for a caller that routes other names through the same code. |
| `wantsRaw(prompt, keymap)` | Does this kind of prompt take press and release times, not gestures? |
| `problems(keymap)` | Every reason a document is not a keymap, as text; `[]` when it is fine. |
| `combos(keymap)` | The combos an engine needs for this keymap. |
| `VERSION`, `RAW` | `2`, `"raw"`. |

An answer is `{source, kind, value, handled, action, choice}`. `source` is `"always"`, `"prompt"`,
`"idle"` or `null`; `kind` is `"choice"` (answer the prompt with `value`), `"do"` (`value` is a
verb's name) or `null`. `handled` is false when the gesture is not the keymap's business. A name
that is not a gesture and a keymap that is not version 2 throw a `RangeError`.

```js
bollardeck.gestures.listen(buttons, function (g) {
  var r = bollardeck.keymap.resolve(g.name, promptShowing ? promptShowing.kind : null);
  if (r.kind === "choice") answer(r.value); else if (r.kind === "do") run(r.value);
});
```

## bollardeck.corpus

**The gate** is the twin of `python/bollardeck/corpus/gate.py`, held to `conformance/corpus-gate/`:
the same verdict, reason, capability, scope and times on every vector.

| | |
| :--- | :--- |
| `judge(manifest, capability, identity, now, standing)` | The verdict. Never throws; anything it cannot read is a refusal with a reason. |
| `readManifest(manifest)`, `decide(reading, capability, identity, now, standing)` | The same in two steps, to read a manifest once and ask many times. |
| `licence(block)` | The licence on paper: `status`, `scope`, `version`, `flags`, `revokedAt`, `expiresAt`, `grants(cap)`, `whyOff(cap)`, `summary()`. |
| `notices(manifest)` | The attribution a client must show: `{corpus_id, artist, edition, license_note, attributions, lines}`. |
| `isVerdict(v)` | Did the gate make this object? A copy of a verdict is not a verdict. |
| `parseTime(text)`, `formatTime(seconds)`, `canonicalCapability(name)` | The licence's time format, and `"study"` to `"musicians_may_study"`. |
| `CAPABILITIES`, `ALL_CAPABILITIES`, `REASONS`, `SCOPES`, `VERDICT_TTL_SEC` | The names it knows, and 900. |

`capability` is one of `transcode`, `store_audio`, `stream_audio`, `store_art`, `store_morpus`,
`musicians_may_study` (or `study`), `export_morpus`, `device_copies`, `see`. `identity` is
`{email, service, player, device}` or absent. `now` is seconds since the epoch, a UTC time string
or a `Date`; absent is this machine's clock. `standing` is `{source, revalidated_at, reachable,
withdrawn, witnessed_at}`; absent is a local manifest. For a cache the gate reads no time earlier
than `revalidated_at` or `witnessed_at` (the latest time the cache has seen on its own clock), so
a clock that is set back does not reopen a licence that has closed.

A verdict is frozen: `{allowed, reason, capability, corpusId, detail, scope, checkedAt,
unverifiedSince, pending, validUntil}`, times in seconds. `asDict()` gives the Python names with
times as UTC strings. The reasons, in the order they are checked: `bad_clock`,
`unknown_capability`, `manifest_invalid`, `licence_ambiguous`, `unknown_scope`, `newer_version`,
`withdrawn`, `not_visible`, `licence_missing`, `licence_invalid`, `revoked`, `expired`,
`not_granted`, `allowed`.

**The hub client** mirrors the read methods of Python's `HubClient`, on `fetch`.

```js
var hub = bollardeck.corpus.hub({ baseUrl: "https://bollawax.org", token: function () { return myToken; } });
hub.corpus("9001-PLACEHOLDERS").then(function (corpus) {
  return corpus.check("stream_audio", { email: who }).then(function (verdict) {
    return verdict.allowed ? corpus.tracks(verdict) : [];
  });
});
```

| | |
| :--- | :--- |
| `hub({baseUrl, token, player, device, actingFor, fetch, clock, timeoutMs, revalidateAfter, credentials, allowInsecureToken})` | A client for one hub. With no `baseUrl` it is the page's own origin. `actingFor` is the person the page acts for. |
| `hub.listing({actingFor})` | A promise of the hub's corpus rows, for that person (`forEmail` is the older name). |
| `hub.corpus(id, {actingFor})` | A promise of one corpus, fetched now, for that person (default: the client's). |
| `hub.version()` | A promise of the hub's version record. |
| `hub.corpusGate()` | A promise of `"enforce"`, `"report"` or `null`: the hub's rollout switch, `corpus_gate` in `/api/version`. Information only; this gate always enforces. |
| `corpus.may(capability, identity, now)` | The gate's verdict from what is in hand. |
| `corpus.check(capability, identity)` | A promise of the verdict, revalidating first when the last check is older than `revalidateAfter` (300 s). |
| `corpus.refresh()` | Revalidate now. |
| `corpus.tracks(verdict)` | A promise of the recordings. Needs an allowed verdict for `stream_audio`, made by this corpus's gate, at most 15 minutes old and from after the last revalidation. |
| `corpus.notices()`, `.manifest()`, `.licence()`, `.standing()` | Metadata. `manifest()` is a copy. |
| `corpus.id`, `.number`, `.slug`, `.name`, `.artist`, `.displayLabel`, `.description`, `.editionLabel`, `.visibility` | The same names as Python, in camel case. |

Rejections: `CorpusUnavailable` (`.reason` is `bad_id`, `not_served` or `unreachable`; `.status`),
`ManifestRefused` (`.reason`, `.problems`), `HubUnreachable` (no answer: `.status` null; or 401,
403, 429, 5xx), `HubError` (an answer that cannot be used; `.status`), `GateRequired` (no allowed,
current verdict), `NotAvailable` (allowed, and the hub has nothing of that kind: `.reason` is
`not_found`, `unreachable`, `not_licensed` or `bad_answer`; `.status`). A track listing the hub
cannot be reached for now rejects with `NotAvailable` (`unreachable`), as in Python.

**Who the client acts for.** A hub's read token alone is study only for a corpus that
is not public: the hub gives such a caller a manifest with the people taken out (no `owner_email`,
`access`, `license_note`, `granted_by` or `statements`) and answers 404 for tracks, audio, art and
bundles. Name the person with `actingFor`; it is sent as `X-Pop-For` and never in a URL. The name
is what the caller says: the hub checks nothing until sign-in arrives in 0.2.5. A request made in
a person's name is sent with `cache: "no-store"`, and a hub must answer corpus routes with
`Vary: X-Pop-For, Authorization` and no shared caching for a corpus that is not public.

What it guards:

- **The token and the identity are the caller's.** `token` is a string or a function returning one
  (or a promise of one), asked at each request. The SDK writes nothing to cookies, `localStorage`
  or any other storage, and the token cannot be read back from the client object.
- **It asks only its own hub.** Every request, and every URL a track listing returns, must be on
  the hub's origin. A redirect is refused, because `fetch` cannot check one before following it.
  A token is not sent over plain `http` except to this machine.
- **Across origins the hub must allow it.** A request to another origin with a token or the
  `X-Pop-Player`, `X-Pop-Device` and `X-Pop-For` headers is preflighted by the browser.

Not in JavaScript this round: a disk cache (so every `corpus()` is a request, and a corpus is
unavailable offline unless it is already in hand), attestation verification, origin discovery,
morpus and audio bytes, and the image release record. The Python client has them.

## Tests

```bash
node --test tests/js/*.test.js
```

They run every vector under `conformance/` through this binding. `python3 -m unittest discover -s
tests` runs them too when node is installed.
